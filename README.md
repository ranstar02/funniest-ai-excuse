The funniest one-line excuse an AI agent gives after failing a task. `main.py` writes that single line (at most 200 characters) to `/output/entry.txt` — no dependencies, no network, fully deterministic.

## Run it

```sh
python3 main.py
```

Then read the entry at `/output/entry.txt`.
